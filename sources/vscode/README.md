# VS Code source snapshots

This directory is reserved for future platform-specific exports of VS Code's **Default Keyboard Shortcuts (JSON)**.

The initial 0.1.0 runtime keymap is bootstrapped from JetBrains' maintained VSCode keymap because it already maps a large set of VS Code workflows to valid IntelliJ Action IDs. The next coverage pass should add canonical VS Code Linux, Windows, and macOS default snapshots here and make those snapshots the generator's primary input.
